Política de Privacidade - DriverStatus

Última atualização: 2 de setembro de 2026

Resumo: o DriverStatus respeita sua privacidade. O aplicativo analisa os drivers do seu computador localmente, sem enviar dados para servidores externos.

Dados coletados

Nenhum dado pessoal é coletado, armazenado ou transmitido.

  • Drivers: A lista de drivers é obtida localmente via Windows SetupAPI. Nenhuma informação é enviada para servidores.
  • Backup: Os backups de drivers são salvos localmente no seu computador, na pasta que você escolher.
  • Configurações: Salvas localmente no seu computador (pasta AppData).

Conexão com a internet

O aplicativo acessa a internet apenas para:

  • Verificar se há atualizações disponíveis (consulta um arquivo JSON no GitHub).
  • Baixar atualizações quando disponíveis.

Nenhum dado pessoal é transmitido nessas conexões.

Funcionalidade de IA

O recurso de diagnóstico assistido por IA copia um resumo técnico dos drivers para a área de transferência. Você decide se e quando colar esse texto em um serviço de IA externo. O DriverStatus não envia dados automaticamente para nenhum serviço de inteligência artificial.

Permissões

  • Acesso ao sistema: Usado para consultar informações de drivers via Windows SetupAPI.
  • Windows Update: Usado para verificar atualizações de drivers disponíveis pelo Windows Update.
  • Administrador (opcional): Solicitado sob demanda apenas para operações que exigem privilégios elevados (backup/restauração de drivers).

Terceiros

O DriverStatus não compartilha dados com terceiros. Não utiliza analytics, rastreamento ou publicidade.
